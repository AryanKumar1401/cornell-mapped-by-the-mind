# Cornell, Mapped by the Mind

An explorable 3D map of a stylized Cornell campus where each landmark holds a social psychology concept, the study behind it, and the connections between the ideas. Class project for PSYCH 2800.

- `index.html` is the page (standalone, no build step needed to view it).
- `campus.html` is the source; `./build.sh` wraps it into `index.html`.
- `connections-poster.png` is a poster of the Connections view.
- Add `#connections` to the URL to open the Connections view directly.
